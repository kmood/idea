# 实施计划：副业机会质量、落地与探索升级

依据：[统一 PRD](../docs/PRD-opportunity-quality-and-exploration-upgrade.md)，用户已于 2026-10-24 确认产品决策。

## 目标

在不降低研究准入标准、不改写历史、不公开私人计划的前提下，将 85 个点子从“结构完整”升级为“可复核的质量与行动缺口”。

## 架构决策

- 第一阶段只读审计，不直接给 85 条正文补写推断，也不自动改变研究状态。
- `readinessStatus` 与 E1–E3、个人匹配、用户私人状态分离；第一阶段先输出建议和缺口，正式持久化留给 records-history 切片。
- 获客路径、探索计划、反馈默认为私人字段，公开研究包不携带这些内容。
- 基础入库只要求现有硬门槛；缺少获客路径、周期或交付边界只阻断候选/精选。
- 研究优先级先补国内非技术行业和国内线下小企业，自动化交付与平台集成作为后续对照与补证。

## 任务顺序

### 第一阶段：只读质量审计

- [x] OQ-01：升级点子质量审计器，输出证据、时效、商业信号和行动缺口。
- [x] OQ-02：补齐索引统计与中文紧贴证据等级的回归测试。

### 检查点一

- [x] 85 条现有点子仍通过基础质量门槛。
- [x] 新审计只生成提示，不修改正文、状态和私人字段。
- [x] records、research、local-web 测试通过。

### 第二阶段：内容复核与质量字段

- [ ] OQ-03：为 85 条生成可处理的批量复核清单，优先国内非技术行业和线下小企业缺口。
- [ ] OQ-04：定义并持久化 `readinessStatus`、`evidenceSignals`、`recencyStatus` 和 `qualityFlags`。

### 第三阶段：行动与展示

- [ ] OQ-05：接入最小交付、获客路径和分阶段探索计划；私人字段与公开研究字段隔离。
- [ ] OQ-06：看板增加质量状态、获客/交付缺口和候选比较，仍不自动触达外部对象。

### 第四阶段：正式入口切换

- [ ] OQ-07：完成迁移、备份恢复、公开导出隔离和回滚演练后，再评估正式入口切换。

## 风险

| 风险 | 对策 |
| --- | --- |
| 关键词审计误判 | 输出提示和理由，不自动改结论；后续补人工复核字段 |
| 把历史报价误当当前机会 | 独立记录信号类型与时效 |
| 私人获客记录进入公开包 | 数据契约分离并加入导出回归 |
| 为补字段而降低入库标准 | 只有候选/精选受行动字段阻断，基础入库规则不变 |
| 国内非技术研究质量下降 | 仍须具体原始讨论、目标对象、问题、赚钱假设、证据和反证 |
