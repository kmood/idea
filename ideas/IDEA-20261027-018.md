# IDEA-20261027-018 无人机幕墙清洗与建筑安全检查

- 首次收录 / 最近实质更新：2026-10-27（Asia/Shanghai）。
- 类型 / 行业 / 市场：建筑物清洁与设施巡检；产业园区、写字楼、物业公司与具备无人机/高空作业能力的清洁服务商。
- 研究状态：暂不适合当前轻量副业；E2，两项独立采购公告重复显示幕墙清洗与高空作业、资质、保险和验收付款需求，但仍是采购需求而非成交，且设备、安全责任、证照和团队门槛很高。
- 服务对象与问题：大型建筑需要一次性外墙/玻璃幕墙清洗，同时检查渗漏、玻璃损坏和结构隐患并提交影像和说明；服务商需承担包工包料、无人机、人工、安全和结果责任。
- 可能赚钱方式：以具备建筑物外立面清洗、无人机运营和安全能力的专业服务商承接整包项目；个人若参与，只可能在合规团队中提供影像整理、巡检报告编排或项目协调，不能无证独立作业。

## 证据、反证与替代

1. CN221：[产服科创大厦玻璃幕墙清洗服务采购公告](https://www.lg.gov.cn/gab/tzgg/content/post_13029299.html)，2026年10月19日龙岗政府在线原文可读。公告明确建筑面积14.67万平方米、外立面30,502.36平方米、清洗1次，采用无人机+人工，控制价77,577.64元，要求清洗后验收、先服务后付款、开具发票，并要求外墙清洗资质、无人机运营管理平台和相关合格证。
2. CN272：[幕墙清洗服务集中采购项目公告](https://www.cec-ec.com.cn/cms/channel/1xmgg1/35919.htm)，2026年4月27日中电商务/CEC电子采购平台原文可读。公告显示北京中电瑞达物业采购7个项目，单项面积约6,200—48,300平方米，合计约10.86万平方米，预算55万元；按次清洗，验收合格并提交有效发票后支付，质量良好可续签，要求建筑物清洁养护相关资质、高处作业证和团体意外保险，不接受分包或转包。
3. 反证与未知：两项公告均未披露成交单位、付款是否已发生、实际设备成本、作业风险、人员数量、复购或个人分包；合同对安全事故的经济及行政/刑事责任承担约束很重。
3. 替代方案包括物业公司、高空清洗企业、无人机服务企业和建筑幕墙检测机构；不能把7.76万元控制价视为成交价或个人收入。

## 个人匹配与未知

用户的IT/AI能力可辅助巡检照片归档、报告模板和隐患清单，但没有无人机运营、外墙清洗资质、高空作业团队和保险，不适合当前轻量副业直接承接。未知项包括成交结果、设备折旧、人工安全成本、资质获取、事故责任、付款周期、复购和报告切片价格。
