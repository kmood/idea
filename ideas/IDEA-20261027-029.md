# IDEA-20261027-029 农村集体田间道路维修机械租赁与石料供应

- 首次收录 / 最近实质更新：2026-10-27（Asia/Shanghai）。
- 类型 / 行业 / 市场：线下设备服务与物资供应；农村集体经济组织、田间道路维修、工程机械租赁和个体工商户。
- 研究状态：暂不适合；E3，官方成交公告确认个体工商户以69220元承接田间路维修机械设备租赁及山皮石采购服务，但设备、台班、石料数量、运输、工期、付款、验收和净利润未知，现场设备与安全责任明显超出当前轻量副业边界。
- 服务对象与问题：村集体经济组织需要维修田间道路，需同时获得工程机械设备租赁和山皮石等材料供应；具备机械、运输和现场作业能力的个体户可通过农村产权交易平台公开竞价承接。
- 可能赚钱方式：以个体工商户或本地机械租赁站身份提供挖掘、装运、整平等设备租赁并供应石料，按项目总价或台班、材料量与运输分别报价；69220元是成交总价，不等于个人收入或净利润。

## 证据、反证与未知

CN278：[木兰县新民镇新合村集体经济组织田间路维修机械设备租赁及山皮石采购成交公告](https://hrbggzy.harbin.gov.cn/zbgs/20261014/f1d334d1-6625-48d0-8ad1-182753031b6b.html)，访问2026-10-27。哈尔滨市公共资源交易中心公告确认木兰县新民镇新合村集体经济组织公开竞价采购该项目，供应商为木兰县娈栖机械租赁站（个体工商户），成交价69220元。公告未公开设备型号与台班、山皮石数量和单价、项目工期、油料、运输、现场安全、验收、付款、实际成本或复购。

CN279：[仁寿县汪洋镇大雅村应急排危机械租赁成交公示](https://www.cdaee.com/nccq/jyxx/018001/018001001/018001001005/018001001005001/20260806/d55c11bd-0956-4124-b523-69233a2d685c.html)，访问2026-10-27。四川农村产权综合交易平台将项目列为绿色通道小额类服务项目，供应商为仁寿县宏伟工程机械经营部（个体工商户），说明农村集体组织也会通过小额类交易采购应急排危机械租赁。页面未公开完整成交金额、设备型号、工期、运输、验收、付款或复购；它与CN278共同支持个体工商户进入该类采购，但不升级E3。

村集体自有机械、当地工程队、建材商和其他机械租赁站是替代；设备折旧、司机人工、燃油、道路天气、石料运输和施工安全可能显著侵蚀毛利。个人若无设备、司机、车辆或合规主体，不应把成交总价当作可直接复制的副业收入。

## 个人匹配与下一步

- 个人匹配：暂不适合当前轻量副业；原因是需要本地设备、运输和现场履约，且安全与资金周转责任高。
- 下一步核验：寻找同类项目的设备/台班、材料量、付款节点和实际履约案例；若出现仅提供排程、撮合或项目资料整理的轻资产分工，再单独评估。
