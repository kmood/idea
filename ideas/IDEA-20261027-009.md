# IDEA-20261027-009 中小企业经营监测问卷与分析报告外包

- 首次收录 / 最近实质更新：2026-10-27（Asia/Shanghai）。
- 类型 / 行业 / 市场：调查执行与经营分析；地方工信部门、中小微企业、问卷调查与研究报告服务机构。
- 研究状态：暂不适合当前轻量副业；E3，官方采购公告明确项目范围、规模、预算和一年服务期，但要求组织协调团队、专职人员与同类业绩，未披露成交、付款、验收或个人分包。
- 服务对象与问题：地方工信部门需要持续获得中小企业生产经营数据，用于月度监测、季度/年度分析和政策研判；承接机构需要完成样本维护、问卷发动、数据审核、访谈和报告交付。
- 可能赚钱方式：以调查研究、企业服务或数据分析机构身份承接年度运行监测项目，再由成员分工完成企业触达、问卷质检、访谈记录和报告整理；97万元是项目总额上限且含约44万元企业补助，不是个人收入或净利润。

## 证据、反证与替代

1. CN203：[广州市工业和信息化局关于遴选2026年广州市中小微企业生产经营运行监测项目承担机构的公告](https://gxj.gz.gov.cn/zw/zfxxgkml/xxgkml/qt/zfcg/content/post_11013139.html)，2026年9月20日原文可读。公告要求完成不少于1500家中小企业问卷、月度分析报告，清理注销/搬迁/低频样本，开展填报培训、月度数据审核、重点行业和重点企业访谈、运行监测座谈会、季度民营经济报告、年度报告及补助经费发放跟踪，并明确总额不超过97万元、其中约44万元发放给参与问卷的企业，服务期一年。
2. 该公告是公开采购需求和预算，不是成交公告；没有确认最终承担机构、实际付款、验收结果、报告质量或企业补助发放完成情况。
3. 主要反证是规模和组织要求：至少1500家企业触达、持续月度交付、样本库管理、培训、访谈和专职人员/同类业绩要求，远超每天两小时和一万元预算的个人轻量副业边界。
4. 替代方案包括已有市场研究公司、行业协会、商会、地方企业服务机构及高校/研究机构；个人可拆分的问卷质检、访谈纪要、数据清洗或报告排版服务尚未有独立采购证据。
