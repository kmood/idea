# IDEA-20261027-013 社区困难人群探访与志愿者培训服务

- 首次收录 / 最近实质更新：2026-10-27（Asia/Shanghai）。
- 类型 / 行业 / 市场：社区社会服务；街道社区、特殊困难老人、困境儿童、志愿者与社会服务机构。
- 研究状态：暂不适合当前轻量副业；E3，官方社区采购公示明确两项成交金额、服务对象、培训与入户服务范围，但社工资质、付款、验收和个人分包未知。
- 服务对象与问题：社区需要组织志愿者并为困难老人、困境儿童提供探访、健康监测、安全排查、人生规划和社区治理活动；承接机构需要完成培训、入户服务、议事会、工作坊和活动资料整理。
- 可能赚钱方式：以社会服务机构或社区项目团队身份承接民生微实事，再拆分志愿者培训、入户探访、活动执行、签到反馈和资料整理；6.30万元和9.95万元是两个项目成交金额，不是个人收入或净利润。

## 证据、反证与替代

1. CN212：[海山街道田东社区2026年第一批民生微实事项目自行采购结果公示](https://www.yantian.gov.cn/isz/tzgg/content/post_12759343.html)，2026年4月29日原文可读。“特殊困难人群邻里守护计划”成交63,014元，服务包括30人志愿者队伍培训、197份慰问蛋糕、40名困难老人入户健康监测/安全排查/主题关爱、10名困境儿童人生规划活动和一对一咨询；“专业志愿赋能·小区治理共建”成交99,517元，服务包括骨干培训、实务工作坊、参访交流、议事会、团建、微治理实践和表彰活动。
2. 公示确认成交单位和金额，但未公开付款节点、验收材料、实际执行人员、社工资质、物料成本或个人/小团队分包。
3. 主要反证是入户服务的安全责任、未成年人和老人服务风险、讲师/社工资质、线下组织和社区信任要求，超出当前轻量副业边界。
4. 替代方案包括社会工作机构、公益发展中心、社区服务中心和专业志愿组织；个人可拆分的培训助教、签到反馈、探访记录整理或活动资料包尚未有独立采购证据。

## 个人匹配与未知

用户的 IT/AI 能力可辅助报名签到、服务记录、反馈问卷、活动资料和报告排版，但没有社工资质、社区资源、入户服务经验或线下团队。未知项包括付款与验收、服务人员资质、入户安全流程、物料预算、实际服务量和个人分包价格。
