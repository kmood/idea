# IDEA-20261027-012 养老服务专干业务培训执行

- 首次收录 / 最近实质更新：2026-10-27 / 2026-11-05（Asia/Shanghai）。
- 类型 / 行业 / 市场：职业培训与养老服务；民政部门、养老服务专干与养老培训服务机构。
- 研究状态：暂不适合当前轻量副业；E3，官方成交公示确认供应商、金额和按参训人数结算方式，但课程内容、师资、付款、验收和个人分包未知。
- 服务对象与问题：民政部门需要提升养老专干业务能力，承接方需要组织培训并按实际参训人数完成服务结算；服务可能涉及课程设计、讲师、场地、报名、签到和培训资料。
- 可能赚钱方式：以养老培训机构或专业讲师团队承接按人计价的培训项目，再拆分课程设计、讲师授课、现场执行和资料制作；5.5万元按80人测算，约为项目口径，不是个人收入或净利润。

## 证据、反证与替代

1. CN210：[全市民政养老专干业务能力提升培训项目中标公示](https://mzj.wuhu.gov.cn/tzgg/gg/8956969.html)，2026年9月17日原文可读。公告确认采购人为芜湖市民政局，南京乐养直训信息科技服务有限公司成交，金额5.5万元，按80人测算并按实际参训人数结算。
2. 公示未公开课程大纲、培训天数、师资资质、场地、付款节点、验收标准、实际参训人数或个人/小团队分包，不能把5.5万元推算为讲师收入。
3. 养老培训的专业性、政府采购资质、线下组织和参训人数波动是主要反证，暂不适合当前轻量副业边界。
4. 替代方案包括养老服务培训机构、职业院校、专业讲师团队和民政系统既有供应商；个人可拆分的课件、签到、资料包或助教服务尚未有独立采购证据。

## 个人匹配与未知

用户的 IT/AI 能力可辅助课件整理、签到表、问卷和培训资料排版，但没有养老业务资质、讲师资源或线下培训团队。未知项包括课程主题、实际人数、结算单价、验收、发票和是否允许分包。

## 下一步核验

寻找养老服务专干培训合同、采购文件和验收材料，重点核验课程/助教/资料整理是否可拆分给个人；若仍需养老专业资质和机构主体，维持“暂不适合当前轻量副业”。
