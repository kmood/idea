# IDEA-20261025-004 个体食材商户承接学校/团餐定时配送

- 首次收录 / 最近实质更新：2026-10-25 首次收录，2026-11-09 补充 CN103 合同附件原文条款（Asia/Shanghai）。
- 类型 / 行业 / 市场：线下供应与配送；学校食堂、机关团餐及本地餐饮采购。
- 研究状态：暂不适合；E3，官方成交明细列出个体商户、成交金额、折扣率、配送频次、食品标准和现场验收，但食品资质、每日履约与垫资要求明显超出用户每天两小时和一万元启动预算的默认轻量边界。
- 服务对象与问题：学校或团餐食堂需要稳定采购肉类、蔬菜、蛋类、米面、水果、糕点和调味品，并在固定时间收到符合食品安全标准的货物；本地肉店、蔬菜店或批零商店通过按品类报价、定时配送和不合格退换满足采购方的持续供应需求。
- 可能赚钱方式：作为本地食材商户参与学校/机关/团餐采购，按市场价折扣、品类毛利和配送服务承接年度或学期供货；公开成交金额是采购合同总额，不等于供应商净利润或个人收入。

## 证据、反证与替代

1. CN100：[扎兰屯市中和镇学校食堂食材采购及配送服务中标（成交）明细](https://www.ccgp-neimenggu.gov.cn/gpx-bid-file/ZF_JGBM_000001/150783/2025/9/8/402881e199060df70199281175d17806/gpx-bidconfirm/402881d29966a94e019970ad44d01596.pdf?accessCode=25bfd3397b9948ad79b392f114130518)，访问2026-10-25，原文 PDF 可读。肉类包由个体商户扎兰屯市中和镇敬常肉店承接，成交总价729,172元、市场价5%；米类/水果/糕点包由扎兰屯市中和镇英姿批零商店承接，成交总价191,886元、市场价2%；蔬菜/蛋类/干调包由个体商户扎兰屯市徐靖常蔬菜店承接，明细要求每日8:00—8:30配送，干调每周1—2次、生鲜当天配送，并接受感官、外观和试用检验，不合格须退换。它是实际个体商户成交与固定履约边界证据，但公告未给付款节点、履约期限完整文本、供货成本、净毛利、复购或实际回款。
2. 本地批发市场、连锁食材配送公司、农产品经销商和学校自采是替代。食品经营许可证、动物防疫/检疫材料、健康证、冷链或保鲜、每日早到、质量退换和食品安全责任构成明显门槛；采购金额大但库存、垫资、损耗与价格波动可能吞噬利润。
3. CN103：[长岭县第四中学大宗食材采购合同](https://www.jl.gov.cn/ggzy/sysggzy/sysjyxx/syszfcg/ccszchtgs/202605/t20260526_9631801.html)，2026-10-25 首次读取、2026-11-09 回源 HTTP 200 复核（无重定向、无 canonical 标签，平台原生公示页）。公示字段：长岭县福兴粮行（个体工商户）为成交供应商，合同金额 1000000 元、签订日 2026-05-25。页面两个附件标签实际指向同一份 7 页扫描 PDF（SHA-256 一致、无文本层，经本地 OCR 识读）：合同第三条写明该金额为“预计年采购金额”，按实际发生采购金额结算；验收以双方签章的配送验收单为准、不合格退换；当月核对、次月第一周开票、收票后若干工作日付款（具体天数扫描不清），允许公对公或公对个人（农户）转账；乙方须一次性缴纳 4 万元履约保证金（食品安全事故可直接启用、期满无违约不计息返还），并随货提供检测/检疫报告、厂家与经销商资质和台账。OCR 未稳定辨认的天数、违约金比例与账号不做推测；合同不包含验收单、发票、银行回单或实际回款，paymentSignal 维持 quote，不升级为实收。详见 `research/deep/2026-11-09-cn103-school-food-contract-terms.md`。
4. 该方向更像主业供应链或本地商户经营，不适合作为用户当前每天两小时、一万元预算的轻量副业；获客路径、探索计划和实验反馈留在私人字段，不进入公开研究包。

## 下一步核验
