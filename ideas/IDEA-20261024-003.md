# IDEA-20261024-003 家政/陪诊平台个人入驻接单与标准化服务

- 首次收录 / 最近实质更新：2026-10-24（Asia/Shanghai）。
- 类型 / 行业 / 市场：本地生活服务；国内家政、收纳、家电清洗、陪诊及部分养老服务平台。
- 研究状态：需补证；E2 公开协议、订单大厅和从业者报道能证明平台渠道、规则与线下履约存在，但“入驻平台”本身不是独立服务机会。现有材料混合家政、收纳、清洗、陪诊、养老等不同交付与责任，且没有同一低风险服务的买方订单—完成—服务者到账—复购链。
- 服务对象与问题：家庭、老人及其他需要上门生活服务的客户，通过平台寻找经过实名、健康/背景和技能审核的服务人员；个人服务者需要获得订单撮合、支付结算和服务规则，而平台需要可验证、可履约的本地服务供给。
- 可能赚钱方式：以个人服务者身份入驻平台，选择日常保洁、收纳、家电清洗、陪诊等自身具备资质且能承担责任的服务线，按平台实收金额分成；公开协议列出日常保洁72%、收纳整理75%、家电清洗73%、医院陪诊80%等基准比例，完成订单后按规则结算。比例来自平台规则，不代表实际订单价格、订单密度或净收入。

## 证据、反证与替代

CN35：[赋界到家家居服务合作协议](https://fujiedaojia.cn/api/agreements/jiaju-service-agreement.html)，访问 2026-10-24。平台协议版本于2026-10-20生效，明确个人或个体工商户双轨入驻、平台撮合/支付/技术支持、完成订单后的T+1结算，以及多个服务品类的基准分成；同时要求实名认证、健康证明、背景审查、技能培训/专项资质和责任规范。协议是供给方公开规则，未证明平台已有足够订单、实际能接单或个人已经收款；养老育儿、病人护理等高风险品类另有更高要求或专项协议。

CN36：[广州海珠区羊城家政基层服务站运营公告](https://www.haizhu.gov.cn/gzhzssj/gkmlpt/content/10/10641/post_10641629.html)，访问 2026-10-24。官方公告要求运营机构将日常订单、服务合同、从业者身份/健康/培训证书录入广州市家政服务综合平台，建立持证、保险、投诉和转介机制，部分居家服务收费由机构自主确定。它独立支持“平台录单+线下服务+资质/转介管理”的交付边界，但这是公共服务站机构运营要求，不是个人平台订单或付款结果。

CN37：[南京网约家政员工作案例](https://shgz.nanjing.gov.cn/lqsx/xjyqt/202504/t20250423_5133938.html)，访问 2026-10-24。报道采访一名入行一个多月的网约家政员：经过4天培训和工具包投入后，3月做20多单、4月预计60单；受访者称扣除平台抽成后日均约73元、月收入约4000元，接单不规律，远距离、超时、提前结束打卡会造成扣款。该案例支持“平台确有具体线下交付与从业者收入/风险反馈”，但收入和订单为单一受访者自述，不能当作普遍行情或用户收益预测。

CN38：[市场监管总局发布3项电子商务家政国家标准](https://www.samr.gov.cn/xw/sj/art/2026/art_cf9249ba04fc488f8a62bb9dd18d5456.html)，访问 2026-10-24。国家标准覆盖平台自营/第三方机构模式、人员入驻审核、身份/健康/背景核验、服务过程、支付、评价和回访，补充了平台化家政服务的合规与质量边界；它是行业规范，不是订单、付款或收入证据。

CN39：[ayi FYI 接单大厅](https://www.ayi.fyi/jobs)，访问 2026-10-24。公开页面按工种和地区展示当前机构订单，页面显示第1/290页、共3470个订单，列出钟点工、家务师、育儿嫂等近期需求及部分地点/薪资信息；平台明确这些信息仅供需求参考，实际报名、价格、档期和服务承诺以机构客服和合同为准。它支持“存在公开订单入口”的判断，但没有证明某个个人已被选中、完成服务或收到款项。

CN40：[ayi FYI 上海家务师订单](https://www.ayi.fyi/jobs/jiawushi/shanghai)，访问 2026-10-24。国内目标城市页面显示第1/7页、共78个订单，列出浦东、黄浦、闵行等地做饭、保洁、辅助照护需求及8,000–13,000元等公开薪资区间；页面同时提示订单仅供参考，实际报名、价格、档期和服务承诺以客服/合同为准，部分条目较旧。它补充了国内城市的具体需求入口，但不证明订单仍开放、用户能报名成功或个人已收款。

CN41：[青藤世家钟点工接单大厅](https://www.qingtengshijia.com/jobs/zhongdiangong)，访问 2026-10-24。独立平台页面显示第1/232页、共2773个钟点工订单，列出上海普陀、浦东、黄浦、徐汇等地做饭保洁、接送儿童等具体需求，部分条目标注40–55元/时或50元/时；页面明确报名、价格、档期和服务承诺须由客服及合同确认。它补充了另一平台的城市化公开需求入口，但仍不证明个人报名成功、服务完成、收款或复购，因此 E2 不变。

CN42：[绍兴家政服务点停摆与欠薪/预付费纠纷](https://timeline.sohu.com/news/xgAbyGhTI5)，访问 2026-10-24。报道记录一个具体家政服务点暂停派单、约40名从业者待结算报酬超过26万元、消费者预付包年保洁无法预约，且官方退款方案在执行上遇到障碍；报道同时引用当事人、记者走访和官方答复。它是对“平台有订单即可稳定接单/结算”的重要反证，提示预付、集中派单、机构现金流和劳动关系风险；不是行业普遍失败率或个人平台收入证据，因此 E2 不变。

CN175：[央视网官方澎湃号《刚需真切，边界未明——一个新兴行业的复杂图景》](https://m.thepaper.cn/newsDetail_forward_34095832)，访问 2026-10-26。报道采访北京个体陪诊师孙婷：通过短视频获客并引流微信，现场陪诊加代问诊一单收费300元，客户包含云南、新疆等地，先服务后付费且未签书面协议，代问诊约占其业务三分之一；同文还对比了机构半天陪诊298元、签协议并投保的做法。该来源补强具体获客、定价和交付责任边界，但核心数据为单一受访者自述，不能证明普遍订单、净收入、支付或复购；同时暴露代问诊、无合同、无保险和医疗责任风险，E2维持。

CN194：[北京市家政服务中介合同（消费者版）](https://scjgj.beijing.gov.cn/bsfw/bmfw/sfwbbm/shxfl/qtwb/202511/t20251105_4262617.html)，访问 2026-10-27。北京市市场监督管理局公开示范文本明确中介服务费、服务者信息与匹配、合同签订、费用支付及防止绕过中介直接交易等条款，补充家政撮合中的收费、责任和防跳单边界；该来源是官方合同示范文本，不是实际订单、付款或复购证据，E2维持。

现有家政公司、社区服务站、其他平台、客户自行寻找服务人员和传统熟人介绍是替代。公开分成未扣交通、耗材、保险、平台保证金、税费、取消/客诉成本；客户财物、人身安全、隐私和养老/陪诊责任风险较高，平台规则可能动态调整。

## 个人匹配与未知

用户的 IT 能力可用于标准化服务记录、客户沟通和轻量流程，但平台只是渠道，该方向核心仍是具体线下服务，不应因平台有技术结算就误判为 IT 远程副业。当前记录没有选定可交付品类，也不知道用户所在地、是否愿意现场履约、是否具备健康/技能资质、平台实际派单量、客户客单价、保证金/保险成本和取消率，因此撤出近期行动池，不进入候选/精选。

## 下一步核验

不再以“平台入驻”整体推进。若继续研究，先拆成一个明确低风险品类，再核验同一服务的买方订单、服务输入/输出、验收、交通/耗材/保险、服务者实际到账与复购；养老护理、代问诊、医疗陪诊和高空作业不得用家政平台通用规则替代专项资质与责任证据。
