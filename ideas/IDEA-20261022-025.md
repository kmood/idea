# IDEA-20261022-025 活动 DJ 业务的线索资格筛选与人工交接自动化

- 首次收录 / 最近实质更新：2026-10-22（Asia/Shanghai）。
- 类型 / 行业 / 市场：销售线索自动化；婚礼与活动 DJ；美国线上业务。
- 研究状态：待验证；E1 具体买方需求，回复中出现固定价方案但未见成交；不进入精选。
- 服务对象与问题：移动 DJ 业务收到 Eventective 新线索后，需要从 Gmail 邮件提取场地、活动类型和时长，按批准的套餐规则回答常见问题、筛选意向、发送 Calendly，并在定制报价或高意向时交给真人；多渠道状态、重复通知和价格误答可能造成漏单或错误报价。
- 可能赚钱方式（研究助手推断）：先卖一次性邮件解析、字段映射和人工交接状态的固定小包，再按验收扩展短信、日历、邮件营销和 DJ Event Planner 同步；报价可按 99–250 美元可靠性切片或更大范围 sprint 验证，但均为供应方报价，不是成交价。

## 证据、反证与替代

GL22：[为 DJ 业务构建 AI 销售代理](https://community.make.com/t/ai-agent-for-dj-business/113000)，2026-08-05发布，访问2026-10-22。原帖作者明确描述 Eventective→Gmail→短信/邮件→Calendly→DJ Event Planner 的线索资格、套餐报价、异常转人工流程；多名回复者提出先解析一封脱敏邮件、建立持久线索状态、限制批准价格并用合成路径验收，固定价建议从 29、99、125、250 美元到 1000 美元不等。回复者是供应方，未证明作者接受任何报价、付款或上线。

现成 CRM、Eventective/Gmail 人工处理、Calendly、DJ Event Planner 原生能力和内部销售助理是替代。原帖没有公开线索量、损失金额、接口权限或实际转化提升；邮件模板不稳定、短信合规、错误报价和人工接管状态会扩大维护责任。大量供应方回复是竞争与自荐信号，不能当买方验证。

## 个人匹配与未知

有条件适合：邮件解析、幂等、状态机、批准规则、测试记录和异步文档与后端技能可复用，首个小包可不接触生产凭据；固定范围交付可控制会议。Eventective 邮件格式、DJ Event Planner 写入能力、短信服务与合规、客户线索量、实际预算、接受报价和后续支持均未知；若要求持续实时销售响应或多渠道故障值守，则不适合每天两小时约束。

## 下一步核验

寻找第二个独立活动服务买方的具体线索自动化需求，优先核对公开预算、书面验收与付款/上线结果；先验证邮件解析和人工交接小包，不把供应方报价当成交。
