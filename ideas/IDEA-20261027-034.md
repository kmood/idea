# IDEA-20261027-034 空调拆装、维修及清洗消毒服务

- 首次收录 / 最近实质更新：2026-10-27（Asia/Shanghai）。
- 类型 / 行业 / 市场：本地设备维护与清洁服务；机关、办公场所、门店物业与空调维修清洗服务商。
- 研究状态：E3，严格校验有效点子；官方小型项目中标公告确认具体买方、服务组合、成交单位和单次项目金额，但设备数量、工位、技术难度、材料、付款验收和复购未知。
- 服务对象与问题：办公或公共场所需要对空调进行拆装、故障维修和清洗消毒，可通过小额直接发包交给本地服务商。
- 可能赚钱方式：以本地空调维修清洗个体户、小型维修队或与持证技师合作的协调方按项目、台数或工时收费；12,870元为单个项目成交价，不等于个人净收入。

## 证据、反证与未知

CN291：[空调拆装、维修及清洗消毒服务](https://www.szns.gov.cn/xxgk/bmxxgk/qcgj/qtgk_157931/xxxm/zhbgg/content/post_12738048.html)，访问2026-10-27。深圳市南山区城市管理和综合执法局小型项目公告显示，项目采用直接发包，2026-04-14确定深圳市宏辉建设工程有限公司中标，价格12,870元，公示后要求中标人24小时内联系对接工作。

空调厂家售后、物业工程团队、连锁维修平台和设备更新是替代；空调维修涉及制冷剂、电气、高处作业、拆装损坏和卫生责任，公告没有说明服务台数、配件、人员资质、保险、付款或验收，不能外推为低风险个人收入。
