# IDEA-20261027-006 民宿管家培训课程与线下培训执行服务

- 首次收录 / 最近实质更新：2026-10-27（Asia/Shanghai）。
- 类型 / 行业 / 市场：乡村民宿从业者培训、民宿管家岗位能力与区域线下培训执行。
- 研究状态：暂不适合；E1，公开竞争性磋商公告明确机构整包需求，但法人、稳定师资与执行团队、跨省现场活动、开票/社保、保险及3万元保证金是已知硬门槛，明显超出每天两小时和一万元内启动边界；个人分包也未获证实。
- 服务对象与问题：乡村民宿管家岗位出现，但从业者专业技能和综合能力不足；项目需要能组织师资、课程、学员食宿、物料、保险、摄影摄像和跨省线下培训的服务商。
- 可能赚钱方式：以培训机构或合规法人身份承接课程开发、讲师组织、班务执行和培训材料交付；个人更可能通过已有机构做课程设计、讲师或项目执行分包，不能绕过法人、开票、社保和现场履约要求。

## 证据、反证与替代

1. CN190：[民宿管家项目培训服务竞争性磋商公告](https://www.cfrd.org.cn/notice/notice_detail.aspx?articleid=5797)，2026年原文可读。中国乡村发展基金会公开招募安徽、甘肃、湖南、浙江、河南、福建、湖北7省的7—9家服务商，服务周期两年，按培训计划下达任务并按合同付款和监督；报价标准为2,500元/人，报价包含人力、差旅、师资劳务、食宿、物料、摄影摄像、宣传、保险、税费和场地等。
2. 同一公告要求服务商具备法人资格、开具财税监制票据、稳定师资团队和项目执行团队，能承办1—2个省级线下培训活动，并缴纳3万元磋商保证金；这些要求说明机会存在，但也构成个人轻量副业的反证和进入门槛。公告未公开最终中标、实际付款、课程大纲或复购结果，不能把2,500元/人当作已实现收入。
3. 替代方案包括职业培训机构、当地文旅院校、行业协会、基金会合作服务商和民宿平台培训；个人直接售卖课程还需要招生、资质、场地、保险和现场安全责任。
4. 获客路径、探索周期、个人匹配和实验反馈属于私人字段，不进入公开研究包；未取得成交公告、服务商反馈或明确个人分包机会前，不进入候选/精选。

## 个人匹配与未知

课程资料、报名/签到/评价数据和培训管理表单只是整包中的辅助工作；原件没有证明这些工作会独立采购给个人。线下讲师、跨省差旅、师资团队、法人合作、保险和3万元保证金是主要限制。即使后续出现成交，也不能自动改变当前适配判断。

## 下一步核验

不继续追机构整包成交；仅在服务商公开、可定位地招募个人课程资料或异步项目协作，并能核验交付、验收、实际到账、工时和责任边界时再复核。不得以个人身份绕过法人、保证金、保险或现场要求。
