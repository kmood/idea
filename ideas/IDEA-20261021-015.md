# IDEA-20261021-015 Square 库存导入预检与差异报告

- 首次收录 / 最近实质更新：2026-10-21（Asia/Shanghai）。
- 类型 / 行业 / 市场：数据预检、导入演练与只读差异报告；线下零售；海外。
- 研究状态：待验证；不进入精选，也不代表用户已选择验证。
- 服务对象与问题：开业、换季或盘点时要把数百个商品及数量、成本、供应商字段导入 Square 的小型零售商；字段看似正确但导入后库存归零、重复 SKU 或成本报表缺字段，临近营业时只能手工补录。
- 可能赚钱方式（研究助手假设）：客户提供脱敏导出文件后，交付字段/表头/SKU/数量预检、少量沙盒式试导计划、导入前后只读差异报告和回滚清单；不直接改生产库存。价格、Square 测试环境能力和客户愿付费程度未知。

## 证据、反证与替代

1. GL23：[导入后商品库存数量显示“售罄”](https://community.squareup.com/t5/Orders-Menu-Items-Catalog/Item-inventory-quantities-showing-Sold-Out-after-importing/td-p/847561)，发布 2026-08-06，访问 2026-10-21。E1 商家称按 29 列模板覆盖库存后所有商品仍显示售罄；为次日开业，最终手工录入 432 个商品数量，耗时近两小时。
2. GL23：[单位成本与供应商未显示在销货成本或报表中](https://community.squareup.com/t5/Retail-eCommerce/Unit-Cost-and-Vendor-Entered-for-new-inventory-in-Item-Library/m-p/839768/highlight/true)，发布 2026-03-31，访问 2026-10-21。独立 E1 商家称商品库里成本与供应商字段正确，但成本/库存报告仍提示缺失。两帖构成同站近期 E2，支持“导入结果需核对”，不证明愿意购买第三方服务。
3. Square 官方支持、平台缺陷修复、采购订单流程、现成 API 和用户自建循环盘点工具是直接替代。问题可能是临时软件缺陷，预检无法保证平台导入成功；接触真实库存与成本数据还需要最小权限和脱敏边界。
