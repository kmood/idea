# IDEA-20261027-028 小型办公地毯周期清洁

- 首次收录 / 最近实质更新：2026-10-27 / 2026-11-05（Asia/Shanghai）
- 类型 / 行业 / 市场：线下服务；办公环境清洁、地毯清洗与小微企业服务。
- 研究状态：需补证；E3，后续官方成交公告确认公司供应商，但成交金额、实际验收、付款、成本和复购未知。
- 服务对象与问题：东莞虎门办公地点需要对会议室、办公室和走廊等约450平方米地毯进行专业清洁，分上、下半年各服务一次，并要求服务方自备设备、承担人工、材料和税费。
- 可能赚钱方式：以本地清洁服务商身份按次或按面积报价，交付地毯清洗和现场恢复；3000元是采购年度预算上限，不是个人收入或净利润。
- 个人匹配：暂不适合当前轻量副业；原因是本地到场、设备、主体资格和现场劳动要求明显，用户所在地与清洁设备未知；若通过本地合规合作方只承担报价、排期或质量记录，仍需验证分工和结算。

## 证据、反证与替代

CN271：[广东亿安仓2026年度地毯清洁服务采购公告](https://www.cec-ec.com.cn/cms/channel/2xmgg1/39083.htm)，访问2026-10-27。公告明确450平方米、每次1个工作日、上下半年两次、验收后14日公对公结算及3000元年度预算，是具体采购需求。按次服务可由个人承接是研究助手推断。

CN313包含同一买方后续采购文件与成交公告：[2026年6月采购文件](https://www.cec-ec.com.cn/cms/channel/2xmgg1/52607.htm)和[2026年7月30日成交公告](https://www.cec-ec.com.cn/cms/channel/2xmgg3/66912.htm)，访问2026-11-05。采购文件将预算修订为含税3500元，仍为450±10平方米、服务期内两次，要求专业设备和合格洗剂；单次验收合格、开票后10个工作日付款，不允许分包。成交公告确认东莞市佳家洁清洁服务有限公司为中标商，但未公开成交金额、验收或付款。该后续结果将证据由E1升为E3；它证明企业需求形成正式授标，不证明供应商到账、净收益或个人轻量承接。

采购方自有保洁、物业公司及本地专业清洁公司是替代；两版文件均要求法人/组织、营业执照和自备设备，后续采购文件明确不允许分包，个人直接承接资格存在障碍。未知项包括最终成交价、设备与耗材成本、税费、实际清洁难度、付款是否发生和是否复购。
