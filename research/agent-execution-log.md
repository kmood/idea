# 自动化执行日志

每次 `idea` 自动化触发都追加一行或一段记录。时间使用 Asia/Shanghai；无新增也记录无变化。日志只保存公开研究过程、测试、提交和推送结果，不保存凭据、Cookie、私有全文或个人操作。

## 记录格式

```text
时间：YYYY-MM-DD HH:MM:SS +08:00
结果：完成 / 无变化 / 失败 / 达到目标
并发状态：已取得运行锁 / 跳过（上一轮仍在执行） / 接管超时锁
阶段：集中收集 / 增量
严格校验点子：N / 200
监测来源：来源 ID 列表或子集说明
变化：新增、更新、合并或无变化
检查：测试与资料检查结果
同步：提交 ID、远程推送结果或无提交
失败原因：无 / 具体原因
下次动作：具体来源、缺口或停止说明
```
