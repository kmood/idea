# 长期质量监控协议

依据：`AGENTS.md`、`CONSTRAINTS.md`、`docs/intent/deep-opportunity-research.md`、`docs/agent/RESEARCH-WORKFLOW.md` 第9节。现有每10分钟心跳负责执行，不另建调度器；本协议不放宽研究门槛。

## 每轮（有界且可恢复）

1. 先读 `research/STATE.md` 顶部断点与失败、最近一轮记录，确认是否已有同轮处理；取实际 Asia/Shanghai 时间。
2. 运行结构与索引一致性检查，比较上一轮的违规清单、候选/精选状态和文件变更。明确区分“新发现问题”“旧问题未变”“检查器误报”。检查失败即禁止提交/推送，绝不改低阈值或跳过测试。
3. 若有新增或变更资料，只复核受影响条目的原始定位、发帖角色、独立性、需求/报价/成交/结算/实际回款差别、反证与未知；从近期行动池撤下不合格条目，保留ID和历史。没有变化时，从上轮断点挑一个最可能改变结论的旧条目核验，不重复堆同类报价。
4. 候选/精选守门：必须有原始可复核买方/交易线索、明确最小交付和售后边界，并在本机私人范围具备获客路径、探索周期与投入/退出条件；任一关键项缺失只能是需补证或更低状态。E3不自动成为候选；机器关键词提示不能替代人工判断。
5. 每轮在 `research/runs/` 写时间、范围、读取成功/失败、审查条目数、候选/精选/新增数、去重、证据与状态变化、减少的未知、反证、剩余缺口、故障、断点和下一步；零新增也记简短记录，同轮重试不重复提交。仅在重要发现、状态改变、故障需处理或用户行动时通知。

## 定期复盘与告警

- 每日首次运行复核全库索引ID/文件、结构缺项、候选守门与私人隔离；之后各轮做增量审查。记录基线与相对上一日的变化，不因数字变大就视为进展。
- 每周选不同证据链抽样人工复读，轮换行业、买方类型、地区与来源；优先检查历史/已关闭事项、供方自述、平台标签、机构整包和强免费替代。发现原始页无法读取时保留上次成功定位，标失效/待复核，不用搜索摘要补位。
- 严重告警：候选缺任一硬门槛、证据从报价误升为实收、公开包含私人内容、重复ID/缺文件、质量测试失败、远程同步冲突。先隔离及记录，再报告；不得自动发布。
- 人工可检查的成功标准：每次状态变化有ID、原始定位、支持与不能支持的主张、反证、历史原因；第三方能复算状态变化。长期指标优先看关键未知减少和证据质量，不看点子总数。

本协议只允许整理公开研究资料，不授权联系客户、访谈、投标、购买、投放、收款或开发副业产品；不绕过验证码、付费墙与站点访问限制。
