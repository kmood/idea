# 正文读取与凭据（R08）

`research.reader.Reader(runtime, run_id, token).read(source_id, url, candidate_id)` 使用 R07 受控传输读取公开页面，返回资料层保存的 ReadReceipt。网络失败、受限或无法解析时返回结构化错误，不产生成功凭据。此接口尚未接入正式 Markdown 研究或定时写入入口。

支持 text/plain、HTML 和 XHTML。HTML 仅提取 article/main 或已识别讨论正文容器中的文字，忽略导航、页脚、表单、脚本、隐藏节点和标题。没有正文、密码输入或已识别验证码页面会被拒绝。不执行网页脚本或网页中的指令。不支持 PDF、JavaScript 渲染页及 XML 订阅格式；这些内容不能算作已读。

正文块 ID 由规范化文字与重复次序确定。指纹覆盖正文块、可见范围和日期信息；同一来源、最终 URL、指纹只生成一份不可变凭据。公开凭据只保存块定位与读取说明，不复制整篇讨论。只有正文范围内唯一且有效的 time datetime 才提供日期；冲突、缺失时保持 unknown，不补造时间。

正文 JSON 存放于数据库同级的 `research-cache/`，目录默认 0700，文件 0600；Git 忽略该目录。缓存以内容摘要命名，原子替换，读取校验摘要，拒绝符号链接文件与非普通文件。本机指针七天后失效；失效、损坏或缺失要求重新读取。当前不会自动删除过期文件，避免误删仍需恢复的工作，后续清理属于 R14/R16。凭据与缓存指针在执行权检查后的同一数据库事务保存；正文文件先写，失败可能留下未引用缓存，但不会出现伪成功凭据。

本机备份包含指针，不要求包含临时正文；异地恢复缺缓存时重读，保留原凭据 ID。公开导出不含缓存指针、正文或私人操作。

验证使用合成网页与注入的传输结果，覆盖正文范围、提示注入作为数据、日期冲突、标题/登录拒绝、幂等历史、缓存篡改/丢失恢复、数据库备份恢复及公开导入导出。网络在线限制仍见 STATE.md；离线测试不代表真实网站读取成功。
